# my-heartopia-tools — asset attribution

This app is an unofficial, non-commercial fan guide. It is not affiliated with
or endorsed by Heartopia or its publisher (XD Entertainment).

## Game-derived assets

| File | What it is | Source | Rights holder |
| --- | --- | --- | --- |
| `src/heartopia/assets/heartopia-world-map.webp` | The in-game world map, used as the daily location background | Screenshot captured from the running game client by the project owner (August 2026) | Heartopia / XD Entertainment |
| `public/og.jpg` | The 1200x630 link-preview card (`og:image`): a contained copy of the world-map screenshot above plus headline text | Same screenshot | Heartopia / XD Entertainment |
| `src/heartopia/assets/roaming-oak-timber.webp` | Roaming Oak Timber item icon | Transparent-background edit derived from an owner-supplied in-game inventory screenshot; the inventory tile and quantity text are removed | Heartopia / XD Entertainment |
| `src/heartopia/assets/flawless-fluorite.webp` | Flawless Fluorite item icon | Same as above | Heartopia / XD Entertainment |

The item icons are edited derivatives, not original asset files distributed by
the game publisher, and must not be described as publisher-provided downloads.
The original screenshots are the archival input and are kept outside this app.

## Rotation and coordinate data

`src/heartopia/data/rotation.json` (the 50-day cycle and anchor) and
`src/heartopia/locationCoordinates.ts` (normalized map coordinates) are
community-observed and owner-calibrated. They are an unofficial schedule that
may change after a game update, and are not live telemetry or an official
publisher feed.

## Removal path

If the rights holder objects to any asset here, please open an issue on this
repository. The affected file will be removed and the site rebuilt without it.
